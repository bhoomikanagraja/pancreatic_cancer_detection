# Pancreatic Cancer Detection

This project contains both a structured healthcare classifier and a handcrafted image classification workflow for pancreas-related imaging data.

## Files

- `data_utils.py` — data loading, preprocessing, and feature engineering utilities for the tabular healthcare dataset
- `train_pancreatic_cancer_model.py` — trains the structured cancer detection classifier
- `predict_pancreatic_cancer.py` — loads the saved structured model and scores new CSV rows
- `image_feature_pipeline.py` — handcrafted image feature extraction and model training utilities
- `train_image_model.py` — trains the image classifier from image/label folders
- `predict_image_model.py` — loads the saved image model and scores a directory of images
- `requirements.txt` — Python dependencies
- `archive/healthcare_dataset.csv` — structured dataset used for training
- `archive/Dataset` — image dataset folders for the handcrafted image workflow
- `predictions.csv` — output file generated by structured prediction runs

## Setup

This project works well with Python 3.12 and uses a scikit-learn Random Forest classifier, which avoids the TensorFlow DLL runtime issue.

1. Install dependencies using Python 3.12:

```powershell
py -3.12 -m pip install --upgrade pip
py -3.12 -m pip install -r requirements.txt
```

If you already have a Python 3.12 installation available, use that interpreter for all commands.

## Model details

- Model type: Random Forest classifier
- Task: binary classification for pancreatic cancer detection
- Positive class: Cancer
- Default decision threshold: 0.2
- Saved artifacts:
  - `model_artifacts/pancreatic_cancer_model.joblib`
  - `model_artifacts/preprocessor.joblib`

## Run commands

### Train the model

```powershell
py -3.12 train_pancreatic_cancer_model.py --data-path archive/healthcare_dataset.csv --model-dir model_artifacts --threshold 0.2
```

### Run predictions on the same dataset

```powershell
py -3.12 predict_pancreatic_cancer.py --input-csv archive/healthcare_dataset.csv --model-dir model_artifacts --output-csv predictions.csv --threshold 0.2
```

### Run predictions on a new CSV file

```powershell
py -3.12 predict_pancreatic_cancer.py --input-csv your_new_data.csv --model-dir model_artifacts --output-csv predictions.csv --threshold 0.2
```

## Image-based workflow

A handcrafted non-CNN image pipeline is also available for the folders under archive/Dataset.

### Train the image model

```powershell
py -3.12 train_image_model.py --image-dir archive/Dataset/X_train --label-dir archive/Dataset/Y_train --model-dir model_artifacts
```

### Score a directory of images

```powershell
py -3.12 predict_image_model.py --image-dir archive/Dataset/X_test --model-dir model_artifacts --output-csv image_predictions.csv
```

## Notes

- The structured CSV model uses patient features such as age, billing amount, gender, blood type, admission type, medication, and test results.
- The structured target label is `Medical Condition == "Cancer"`.
- The handcrafted image workflow uses grayscale resizing, histogram and statistical features, and a Random Forest classifier.
- Image model artifacts are saved to `model_artifacts/image_model.joblib` and `model_artifacts/image_feature_config.joblib`.
- Lowering the threshold for the structured model can increase cancer recall, which is useful for medical screening scenarios.
